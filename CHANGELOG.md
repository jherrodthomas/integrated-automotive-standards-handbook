## [1.0.0] — 2026-04-11

### Added

- **Part I (Chapters 1–3):** Foundation and integration framework covering all six standards — ISO 26262:2018, ISO/SAE 21434:2021, ISO 21448:2022, ISO/PAS 8800:2024, ISO 9001:2015/IATF 16949:2016, and ASPICE v4.0 — with structural overviews, key concepts, and a unified V-model integration framework.
- **Part II (Chapters 4–10):** Clause-level cross-mapping across every lifecycle phase from organizational setup through decommissioning. Each chapter includes Rosetta Stone tables, commonality/gap analysis, integrated activity checklists, and AEB worked mini-examples.
- **Part III (Chapters 11–12):** Two end-to-end worked examples — ADAS Forward Camera ECU (ASIL B(D), CAL 3) and AI Pedestrian Detection on NVIDIA Orin (ASIL C, CAL 4) — demonstrating full lifecycle integration.
- **Part IV (Chapters 13–15):** Practical tools including 8 integrated work product templates (consolidating 30+ siloed documents), audit & assessment readiness guide, and tool qualification guidance (TCL 1–3, ML tool qualification).
- **Part V (Appendices A–D):** Master cross-reference matrix (80+ activities), 50+ IEEE-format references, 150+ acronym glossary, and revision history.
- 109 cross-mapping tables across all chapters.
- README with role-based reading guide and project roadmap.
- CONTRIBUTING guide with standards-specific contribution process.
- CITATION.cff for machine-readable citation metadata.
- GitHub issue templates for clause corrections, worked examples, and standard coverage requests.
